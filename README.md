# 📊 AI Data Analyst Agent

> **"Turn your data into clear insights with AI."**

A full-stack enterprise web application and AI-powered analytics agent that transforms raw tabular data (CSV/Excel) into automated executive insights, interactive Plotly visualizations, and data quality audits.

---

## 🌟 Key Features

- **Automated Statistical Profiling**: Instant dataset summary (rows, columns, missing value ratios, duplicates, numeric distributions).
- **AI Analyst Assistant**: Chat with your data in natural language powered by Google Gemini AI with deterministic local Pandas execution.
- **Dynamic Plotly Visual Studio**: Custom responsive bar, line, pie, scatter, histogram, and box plot renders.
- **Automated Insights Generator**: Executive summary cards identifying performance drivers, correlations, skewness, and anomalies.
- **Data Health Audit**: Quality scoring with actionable cleaning recommendations.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3 (Modern Light SaaS Theme), JavaScript (ES6+ fetch API), Plotly.js
- **Backend Framework**: Python, Flask
- **Data Engine**: Pandas, NumPy
- **AI Model**: Google Gemini API (`google-generativeai`)
- **Environment**: Python Virtual Environment (`venv`), `python-dotenv`
